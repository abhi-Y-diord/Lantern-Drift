# Lantern Drift

A calm night-sky game. Hold to float your lantern up, release to sink, collect fireflies, and dodge the frogs and the bird.

- Green frog: grabs with its tongue
- Yellow frog: jumps and strikes (+50 for dodging)
- Red frog: throws mud (+80 for dodging)
- Pick Low / Medium / High before a run. Each level keeps its own best score (saved in your browser).

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and `README.md`.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute, your game is live at `https://<your-username>.github.io/<repo-name>/`.
